# Pole Sport Medellin Landing

Landing page for Pole Sport Medellin built with Astro + React islands and Tailwind.

## Stack
- Astro (SSG with islands)
- React (interactive components)
- Tailwind CSS
- Astro Sitemap

## Routes
- /es (canonical)
- /es/precios
- /es/contactanos
- /en
- /en/pricing
- /en/contact

- TODO_MAPS_LINK
